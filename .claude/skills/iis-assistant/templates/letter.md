# Letter template (خط / درخواست)

```
بسم اللہ الرحمن الرحیم
                                   [ادارے کا لیٹر ہیڈ: لوگو + نام + پتہ + فون]
حوالہ نمبر: IIS/[سال]/[نمبر]                         تاریخ: [عیسوی] / [ہجری]

بخدمت جناب [عہدہ و نام]
[ادارہ / دفتر، شہر]

موضوع: [ایک سطر میں موضوع]

محترم/مکرم جناب،
السلام علیکم ورحمۃ اللہ وبرکاتہ

[پیراگراف 1: تعارف/پس منظر]
[پیراگراف 2: اصل گزارش، واضح اور مختصر]
[پیراگراف 3: شکریہ / امید]

والسلام
[نام]
[عہدہ]، انسٹیٹیوٹ آف اسلامک اسٹڈیز ڈہرکی
[دستخط / مہر]
```
Notes: reference numbers are logged in `institute/tasks.md` under "Outgoing letters". English version for government/bank recipients.
